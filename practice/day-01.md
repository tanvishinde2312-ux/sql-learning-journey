# 📝 Day 01 — Introduction to SQL Practice

## 🧠 Conceptual Questions

### Q1. What does SQL stand for?

**My Answer:**
Structured Query Language.

---

### Q2. What is a relational database?

**My Answer:**
A relational database is a collection of multiple tables where the data in the tables is related to each other.

---

### Q3. In a table, what does a row represent?

**My Answer:**
A row represents one record or entity in a table.

---

### Q4. What does a column represent?

**My Answer:**
A column represents an attribute or property of the data.

---

### Q5. If you have a `Students` table with columns `id`, `name`, `branch`, and `year`, which part represents one student's complete information — a row or a column?

**My Answer:**
A row represents one student's complete information.

---

## 💡 Key Learning

* SQL stands for **Structured Query Language**.
* A relational database contains **related tables**.
* A **row** represents a record/entity.
* A **column** represents an attribute/property.
