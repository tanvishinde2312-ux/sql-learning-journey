# 📚 Day 01 — Introduction to SQL

## 📚 What I Learned

### What is SQL?

SQL (Structured Query Language) is a language used to query, manipulate, and transform data stored in relational databases.

### Relational Database

A relational database stores data in **tables**. Multiple tables can contain related data.

### Table Structure

* **Row** → Represents one record/entity.
* **Column** → Represents an attribute/property.

Example:

| ID | Name  | Branch   | Year |
| -- | ----- | -------- | ---- |
| 1  | Tanvi | Computer | 3    |
| 2  | Riya  | IT       | 3    |

Here, each row represents one student's record, while `Name`, `Branch`, and `Year` are attributes.

### 💻 Important Concepts

* SQL → Structured Query Language
* Database → Collection of organized data
* Table → Collection of rows and columns
* Row → Record/entity
* Column → Attribute/property
* Relational database → Database containing related tables

### 📝 Examples

A database may contain tables such as:

```text
Students
Departments
Courses
Examinations
```

These tables can be related using common information such as IDs.

### 💡 Key Takeaway

> SQL is used to work with data stored in relational databases. Tables contain rows (records) and columns (attributes).
